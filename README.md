### ✨ Recursos

- ⚡ **Servidores em segundos**, só PT-BR e automáticos
- 🎞️ **Player completo:** Picture-in-Picture, toque duplo para avançar 10 s, qualidade e proporção de tela, "Pular abertura" e próximo episódio automático
- 📥 **Download offline** dentro do app
- 👥 **Assistir juntos:** sala com voz e chat para ver com amigos
- 📺 **TV ao vivo** com histórico de canais
- 🔔 **Atualização dentro do app**, com as novidades de cada versão
- 🧩 **Addons:** cada pessoa configura do jeito que quiser
